# Fuentes

`run.bat` (via `tools/setup_assets.py`) descarga aquí fuentes libres (OFL):
Nunito Black (estilo "Frase") y Montserrat Black / Black Italic (Karaoke y Título gancho).

Puedes añadir cualquier `.ttf`/`.otf` y usar su nombre de familia en el preset.
Si una fuente no está, libass usa una del sistema.
